# ayufan fork — defconfig changes vs upstream

Changes applied on top of upstream u-boot by the ayufan commits.
All boards share the common patterns listed first, then per-board specifics follow.

## Common patterns across boards

- `CONFIG_SYS_MMCSD_RAW_MODE_U_BOOT_SECTOR=0x200` — raw MMC sector for U-Boot
- `# CONFIG_SPL_SHARES_INIT_SP_ADDR is not set` + `CONFIG_SPL_STACK_R=y` — separate SPL stack

## pinebook-pro-rk3399

- `CONFIG_SPL_DM_SPI=y` — SPI DM in SPL
- `# CONFIG_ANDROID_BOOT_IMAGE is not set`

## quartz64-a-rk3566 / quartz64-b-rk3566

- `CONFIG_SYS_MMCSD_RAW_MODE_U_BOOT_SECTOR=0x200` only

## quartzpro64-rk3588

- `CONFIG_SPL_ROCKCHIP_COMMON_BOARD=y`, `CONFIG_ROCKCHIP_SPI_IMAGE=y` — enable SPI image build
- `CONFIG_SPL_SPI_FLASH_SUPPORT=y`, `CONFIG_SPL_SPI=y` — SPI flash in SPL
- `CONFIG_SPL_SPI_LOAD=y`, `CONFIG_SYS_SPI_U_BOOT_OFFS=0x60000` — SPI boot offset

## rock-pi-4-rk3399

- `CONFIG_TARGET_EVB_RK3399=y` instead of `CONFIG_TARGET_ROCKPI4_RK3399=y` — changed board target
- `CONFIG_SF_DEFAULT_BUS=1` removed
- `CONFIG_SPL_STACK=0x400000`
- `CONFIG_SPL_STACK_R=y`, `CONFIG_SPL_STACK_R_MALLOC_SIMPLE_LEN=0x10000`
- `CONFIG_SYS_SPI_U_BOOT_OFFS=0x80000` (was `0xE0000`)

## rock64-rk3328

- TPL support: `CONFIG_TPL_ROCKCHIP_COMMON_BOARD=y`, `CONFIG_TPL_LIBCOMMON_SUPPORT=y`, `CONFIG_TPL_LIBGENERIC_SUPPORT=y`, `CONFIG_TPL_SYS_MALLOC_F_LEN=0x800`
- `CONFIG_TARGET_ROCK64_RK3328=y`, `CONFIG_SPL_DRIVERS_MISC=y`
- Stack: `CONFIG_SPL_STACK_R_ADDR=0x600000`, `CONFIG_SPL_STACK=0x400000`
- SPL BSS: `CONFIG_SPL_PAD_TO=0x7f8000`, `CONFIG_SPL_HAS_BSS_LINKER_SECTION=y`, `CONFIG_SPL_BSS_START_ADDR=0x2000000`, `CONFIG_SPL_BSS_MAX_SIZE=0x2000`
- `CONFIG_SPL_BOARD_INIT=y`, `CONFIG_SPL_I2C=y`
- `CONFIG_CMD_USB_MASS_STORAGE=y`
- `CONFIG_LED=y`, `CONFIG_MISC=y`, `CONFIG_ROCKCHIP_EFUSE=y`

## rock5b-rk3588

- `CONFIG_SPL_STACK_R=y`

## rockpro64-rk3399

- Boot image: `# CONFIG_ANDROID_BOOT_IMAGE is not set`, `CONFIG_SPL_FIT_SIGNATURE=y`, `CONFIG_LEGACY_IMAGE_FORMAT=y`
- Bootstage: `CONFIG_BOOTSTAGE=y`, `CONFIG_BOOTSTAGE_REPORT=y`, `CONFIG_USE_PREBOOT=y`, `CONFIG_CMD_BOOTSTAGE=y`
- SPL stack: `CONFIG_SPL_STACK_R=y`, `CONFIG_SPL_STACK_R_MALLOC_SIMPLE_LEN=0x10000`
- Commands: `CONFIG_CMD_GPIO=y`, `CONFIG_CMD_I2C=y`, `CONFIG_CMD_USB_MASS_STORAGE=y`, `CONFIG_CMD_PMIC=y`, `CONFIG_CMD_REGULATOR=y`
- SPI flash: `CONFIG_SPI_FLASH_WINBOND=y`
- USB: `# CONFIG_SPL_DM_USB is not set`, `CONFIG_USB_DWC2=y`, `CONFIG_ROCKCHIP_USB2_PHY=y`, `CONFIG_USB_GADGET=y`
